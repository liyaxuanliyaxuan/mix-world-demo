# MiX-World Project Page

Static research project page built with Astro + TypeScript.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build          # -> dist/
npm run build:review   # -> dist-review/
npm run build:public   # -> dist-public/
```

All videos are precomputed model predictions. No analytics, no tracking, no server-side components.
